## 这是什么

F1 视频工具启动器是一个**零依赖、单文件、纯浏览器**的 F1 短视频制作工具合集。双击打开 HTML，启动器内嵌全部四个工具（含 22 位车手头像、字体、音效等全部素材），加载后即可使用，全程不需要联网、不需要安装任何软件。

导出走浏览器原生渲染管线（Canvas + MediaRecorder / mp4 / webm 硬件 muxer），1920×1080 · 60fps · 85 秒成片一键导出。

## ✨ 四大工具

### [1] F1 发车格视频制作工具
- **22 位车手自动排位**，一键生成完整发车格
- 内置全部车手头像，支持替换
- 车手姓名、号码、车队色逐项可改
- 逐帧预览，0/1/2/3 快捷键打点，空格播放/暂停

### [2] F1 杆位圈视频制作工具
- **官方版式入场动画**，自动复用发车格的头像资源
- 车手入场片头、展开停留时长可调
- 打点系统：圈开始 / S1 点 / S2 点 / 过线 四个关键点
- 帧率、清晰度、背景音乐均可配置

### [3] 左下角计时段
- 转播画面同款**紫 / 绿 / 黄语义配色**（最快圈紫、个人最佳绿、常规黄）
- **差距条**可视化，与真实转播排版逐像素对齐
- 可作为独立片段或叠加素材使用

### [4] F1 车队电台 GIF / 视频生成器
- **对白、队色、号码全部可改**
- 车队电台对白逐条添加，每条间隔与展开停留可调
- 一键导出 GIF 或视频，直接发社交平台

## 🚀 使用

1. 下载 `F1视频工具启动器_V3.html`
2. 双击用 Chrome / Edge 打开（推荐桌面端 Chromium 内核浏览器）
3. 首页点选工具，或按键盘 `1` / `2` / `3` 快速启动，`Esc` 返回启动器
4. 导入头像 / 队徽，调整参数，点导出

## 📦 导出能力

- **格式**：MP4（H.264/AAC）、WebM（VP9/Opus）、GIF
- **分辨率**：1920×1080（16:9）
- **帧率**：60fps
- **音频**：支持背景音乐导入，导出时自动混音
- **其他**：可保存当前帧为 PNG，可存入相册 / 分享
