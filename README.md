## 这是什么

**零依赖、单文件、纯浏览器**的 F1 短视频制作工具合集。双击打开 HTML 即可使用——启动器内嵌全部四个工具，以及 22 位车手头像、字体、音效在内的所有素材，全程离线运行，不装任何软件。

导出走浏览器原生渲染管线（Canvas + MediaRecorder / mp4 / webm 硬件 muxer）。

## ✨ 四大工具

| # | 工具 | 一句话 |
|---|---|---|
| 1 | **发车格视频** | 22 位车手自动排位，姓名 / 号码 / 队色逐项可改，一键生成完整发车格 |
| 2 | **杆位圈视频** | 官方版式入场动画，圈开始 / S1 / S2 / 过线四点打点，帧率与清晰度可调 |
| 3 | **左下角计时段** | 转播同款紫 / 绿 / 黄语义配色（最快圈 / 个人最佳 / 常规），差距条与真实排版逐像素对齐 |
| 4 | **车队电台** | 对白、队色、号码全部可改，逐条添加电台对白，一键导出 GIF / 视频直接发社交平台 |

通用能力：逐帧预览、0/1/2/3 快捷键打点、空格播放/暂停、头像与队徽随时替换。

## 🎬 为什么选它

- **单文件** — 全部工具、素材、字体、音效打包在一个 HTML（约 15 MB），拷走就能用
- **离线可用** — 不联网、不安装、无账号，浏览器双击即开
- **快** — 导入头像队徽，85 秒导出成片
- **像素级复刻** — 界面与排版对着 F1 官方转播画面逐像素校对
- **完全可定制** — 姓名、号码、队色、队徽、对白、打点、时长全部可改

## 🚀 快速开始

1. 下载 [`F1视频工具启动器_V3.html`](F1视频工具启动器_V3.html)
2. 双击用 **Chrome / Edge** 打开（推荐桌面端 Chromium 内核浏览器）
3. 首页点选工具，或按 `1` / `2` / `3` 快速启动，`Esc` 返回启动器
4. 导入头像 / 队徽，调整参数，点导出

## English

A single-file, zero-dependency F1 short-video toolkit that runs entirely in the browser. Four tools in one launcher — starting grid, pole-position lap, broadcast-style timing lower-third, and team-radio clips — with all 22 driver avatars, fonts and sound effects embedded in one ~15 MB HTML file. Exports 1080p60 MP4/WebM/GIF in about 85 seconds, fully offline, no install required.
